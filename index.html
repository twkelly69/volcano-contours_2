About this site

Use this template to publish maps, charts, notebooks, or documentation. Everything is static, so GitHub Pages can serve it directly—no build step required.

Static-first

All assets live in the repository, making previewing locally as simple as opening index.html in a browser.

GitHub Actions included

A Pages workflow is ready to deploy on every push to the work branch. Adjust the branch name in .github/workflows/pages.yml if needed.

Deployment quickstart

Follow these steps to publish automatically to GitHub Pages.

  1. Enable GitHub Pages. In repository settings, set Source to GitHub Actions.
  2. Push your changes. Commits to the work branch will trigger the workflow.
  3. Wait for deployment. GitHub will build and publish the site. The URL appears in the Actions log and the Pages settings page.

Want to host from another branch or folder? Update the on.push.branches and upload-pages-artifact path values in the workflow.

Ready to customize? Edit index.html and commit to deploy via GitHub Pages.
