使用這個範本來發布地圖、圖表或專案說明。所有資源都放在版本庫中，適合直接部署到 GitHub Pages。

互動強調

指向縣市時，區塊會放大並同步更新右側資訊卡，便於投影片或展示使用。

GitHub Actions 部署

Pages workflow 會在推送 work 分支後自動發布。可於 .github/workflows/pages.yml 調整來源分支。

部署步驟

按照以下說明即可在 GitHub Pages 上展示互動地圖。

  1. 啟用 GitHub Pages。 在 repository 設定將 Source 設為 GitHub Actions。
  2. 推送更新。 將修改提交並推送到 work 分支，workflow 即會觸發。
  3. 等待發布。 GitHub 會建置並發布網站，網址可在 Actions log 與 Pages 設定頁找到。

若需從其他分支或資料夾發布，請更新 workflow 中的 on.push.branches 與 upload-pages-artifact 的 path。
